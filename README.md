## 📦 两种套餐，按需选择

### 🪞 Claude 镜像套餐（面向用户）

Web 端直接使用，体验与 Claude 官网一致：

- 登录账号即用，无需 API Key、无需信用卡
- 覆盖 Claude 全系模型
- 额度制计费，无 5 小时额度限制
- 适合个人与团队日常使用

### 🔌 API 套餐（面向开发者）

提供 Claude / Gemini / OpenAI 等大模型标准 API 接口：

- **Chat 接口**：对话 / 文本生成 / 工具调用
- **Image 接口**：图像生成与编辑（独立计费）
- 两类接口对应不同的 API Key，不可混用
- 按官方原价计费，可前往各厂商官网查询单价
